# ServiceHub – Multi-Tenant Service Marketplace

ServiceHub is a web-based multi-tenant service marketplace that connects customers with service providers through an easy-to-use online platform.

Customers can discover services, search and filter available services, select suitable dates and times, provide booking details and location, and manage their bookings. Merchants can manage their services and view customer bookings, while administrators can monitor users, services, and bookings through an admin dashboard.

## ✨ Features

### Customer
- User registration and login
- Browse service categories
- Search and filter services
- View service details
- Select booking date and time
- Future date/time validation
- Provide address and phone number
- Capture booking location using GPS
- Create service bookings
- View personal bookings

### Merchant
- Merchant authentication
- Add services
- Manage merchant services
- View customer bookings
- Service category management

### Administrator
- Secure admin authentication
- View total users
- View total services
- View total bookings
- View all registered users
- View all listed services
- View all customer bookings
- Monitor merchants and customers
